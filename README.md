# Therion's Pit

## 📖 Overview
**Therion's Pit** is a 3D multiplayer action RPG set in an ancient, ruined structure. Players must form a party, choose their class, and work together to defeat powerful bosses. 

## Features
*   **Multiplayer Lobby:** Local Host/Client connections.
*   **Unique Character Selection:** Choose from multiple classes (Mage, Knight, Ninja, Archer) with no duplicate classes allowed in a single party.
*   **Server-Authoritative Gameplay:** Built with Unity Netcode for GameObjects to ensure smooth, cheat-resistant combat and movement.
*   **Custom KCC Movement:** Responsive, physics-based character controllers with jumping and sprinting.

## Built With
*   **Engine:** Unity 6 (URP - Universal Render Pipeline)
*   **Networking:** Unity Netcode for GameObjects, Unity Relay, Unity Transport
*   **Character Controller:** Kinematic Character Controller (KCC)
*   **UI:** TextMeshPro

## Getting Started

### Prerequisites
*   Unity 6000.0.5f1
*   Git installed on your machine

### Installation
1. Clone the repository:
   ```bash https://github.com/Michellle-ima8901/TherionsPit.git
2. Open the project folder in Unity Hub.
3. Wait for Unity to import all assets and packages.
4. Open the MainMenu scene (located in Assets/Scenes/).
5. Press Play!

📂 Project Structure
* Assets/Scripts/ - Contains all C# gameplay and networking scripts.
* Assets/Prefabs/ - Networked player characters and environment objects.
* Assets/FinalisedAssets/ - 3D models, textures, and animations.
