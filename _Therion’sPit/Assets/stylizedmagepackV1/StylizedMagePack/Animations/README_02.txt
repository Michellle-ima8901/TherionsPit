⚠ IMPORTANT NOTE


* DO NOT use MAGE_ANIMATIONSV1 as the player character.

Use the models inside the Models folder or the prefabs that are already provided.


   * The model included in MAGE_ANIMATIONSV1 is only a reference for hierarchy naming. It is not meant to be used as a playable character and does not affect gameplay mechanics or visuals of the asset.


   * If you want to use the animations, use the humanoid_wizard or create a new Animator Controller. If your character is Humanoid, simply create a new state in the Animator and assign the animation clip.


   * If the asset receives animation updates, only the MAGE_ANIMATION FBX will be affected.
Model updates will affect only the files inside the Models folder
