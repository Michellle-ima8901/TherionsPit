=== VERSION INFORMATION FOR THIS PACKAGE ===

This package includes TWO versions of the characters: V1 (original/legacy) and V2 (remaster).

RECOMMENDATION: use V2. It features an improved rig and mesh, updated 
textures, and a lighter/more optimized result overall.

We chose to keep V1 available instead of removing it, since it's still 
solid content and some users may prefer its original look or already 
have projects built around it.

IMPORTANT - COMPATIBILITY:
- V1 is the original/legacy version of the pack, kept for users who 
  already use it or prefer that style.
- Since the V2 rig/mesh was improved compared to V1, animations from V2 
  may not look natural when applied to the V1 character (and vice versa). 
  They will technically work, but the visual result may not match your 
  expectations. We recommend using each version's animations with its 
  matching character.
- Weapons/staffs are shared between both versions and work normally 
  with either one.
- Spell VFX were kept only in the V1 folder. If you're using V2, you 
  can still use the V1 VFX normally — they don't depend on the character.

Summary:
✔ V2 = recommended, improved look, more lightweight
✔ V1 = original/legacy, kept for compatibility and users who prefer the old style
✔ Weapons/Staffs = shared between V1 and V2
✔ VFX = only available in the V1 folder (but usable with V2 too)
