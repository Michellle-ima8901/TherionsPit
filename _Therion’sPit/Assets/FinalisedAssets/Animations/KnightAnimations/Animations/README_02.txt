⚠ IMPORTANT NOTE


* DO NOT use Knight_AnimationsV1 as the player character.

Use the models inside the Models folder or the prefabs that are already provided.


   * The model included in Knight_AnimationsV1 is only a reference for hierarchy naming. It is not meant to be used as a playable character and does not affect gameplay mechanics or visuals of the asset.


   * If you want to use the animations, create a new Animator Controller and drag then into it. If your character is Humanoid, simply create a new state in the Animator and assign the animation clip.


   * If the asset receives animation updates, only the Knight_AnimationsV1 FBX will be affected.
Model updates will affect only the files inside the Models folder
